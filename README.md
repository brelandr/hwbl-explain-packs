# HWBL Explain Packs

Public catalog and release assets for [Hidden Word Bible Lessons](https://thehiddenword.org) shared AI explanations.

- **Churches / plugin sites:** read-only. Install packs from the catalog URL — no GitHub account required.
- **Hub (thehiddenword.org):** publishes ZIPs via GitHub Releases using a private token stored only on the hub.

## Catalog

Raw URL used by the plugin by default:

`https://raw.githubusercontent.com/brelandr/hwbl-explain-packs/main/explain-packs-catalog.json`

## Pack ZIP layout

Each GitHub Release asset is one ZIP containing `manifest.json` + `explains.jsonl`.
